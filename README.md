# Mobile Open Animation for Windows

让 Windows 拥有类似智能手机的开屏动画。

## 特性

- **免注入、免 Hook**
- **免安装、不写全局配置**
- **无需额外安装依赖**
- **支持动态圆角**
- **Material 3 曲线**
- **遵循 Windows 个性化设置**
- **无遥测、无联网**

## 局限性

- **UWP / WinUI 应用**
- **带反作弊的在线游戏、部分安全软件**（这类程序的窗口不接受外部程序改变其状态）
- **对话框、弹窗、工具窗口**
- **不是通过用户点击弹出来的窗口**
